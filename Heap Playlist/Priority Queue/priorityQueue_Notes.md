A `priority queue` is an abstract data type where each element is assigned a priority value, and elements rather than their insertion order

- **Max-Priority Queue** : Elements with higher numerical values hold higher priority. The maximum value is always at the front and removed first

- **Min-Priority Queue** : Elements with lower numerical values hold higher priority. The minimum value is always at the front and removed first


So the Priority Queue is basically `Heap`(Max Heap or Min Heap)
